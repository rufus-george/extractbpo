## Services

- **Live transfers:** qualified callers connected to your sales team on the same call

- **Social media lead generation:** Facebook and Meta ad campaigns

## Updating the site

1. Open `index.html` in this repo and click the pencil icon (Edit).
2. Make your change, then click **Commit changes**.
3. GitHub Pages republishes automatically. Changes appear in 1 to 2 minutes. Refresh the page, or clear your browser cache if you still see the old version.

Common edits in `index.html`:

- **Contact details:** search for `tel:`, `mailto:`, and `wa.me` to change the phone, email, and WhatsApp links.
- **Contact form:** the form sends submissions through Formspree. Its address is in the `<form action="...">` line.
- **Text and services:** edit the wording directly between the HTML tags.
- **Colors:** the color values are at the top of the file under `:root`.

## Hosting

The site is hosted free on GitHub Pages:

- Repository name: `rufus-george.github.io`

To use your own domain later, add it in Settings → Pages → Custom domain.
